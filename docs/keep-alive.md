# Как не дать бесплатному Render «засыпать»

Бесплатный сервис Render засыпает после ~15 минут без запросов, а первый запрос после этого
«будит» его около минуты. Чтобы на показе или в работе приложение отвечало сразу, достаточно,
чтобы кто-то обращался к нему чаще, чем раз в 15 минут.

## Вариант 1 — UptimeRobot (проще всего, бесплатно)

1. Зарегистрируйтесь на https://uptimerobot.com (бесплатный тариф).
2. **+ New monitor** → Monitor Type: **HTTP(s)**.
3. Friendly Name: `EcoStep backend`.
4. URL: `https://ВАШ-АДРЕС.onrender.com/health` (адрес сервиса на Render + `/health`).
5. Monitoring Interval: **5 минут** (подойдёт любой интервал меньше 15 минут).
6. **Create Monitor**. Заодно сервис пришлёт письмо, если бэкенд когда-нибудь упадёт.

Проверка: через 20–30 минут откройте Render → ваш сервис → **Logs**: там должны регулярно
появляться строки `GET /health ... 200 OK`, а сервис не должен уходить в состояние Sleeping.

## Вариант 2 — cron-job.org

1. https://cron-job.org → бесплатная регистрация → **Create cronjob**.
2. URL: `https://ВАШ-АДРЕС.onrender.com/health`, расписание: каждые 10 минут.

## Про часы бесплатного тарифа

На бесплатном тарифе Render даёт 750 «часов работы» в месяц на весь аккаунт. Один сервис,
работающий круглосуточно, занимает 720–744 часа, то есть укладывается. Если в том же
аккаунте будут работать другие бесплатные сервисы, часы делятся между ними.
